# 本地版本备份与恢复工具

面向普通项目文件的本地备份工具。当前实现最小的单快照功能：递归备份普通文件目录，并可将快照恢复到全新目录。

仅依赖 Python 3 标准库（`os` / `pathlib` / `shutil` / `json` / `argparse`）。

## 用法

```bash
# 备份：将 SOURCE 递归备份到新建的 SNAPSHOT 目录
python backup.py backup SOURCE SNAPSHOT

# 恢复：将 SNAPSHOT 恢复到新建的 DEST 目录
python backup.py restore SNAPSHOT DEST
```

成功时退出码为 0，标准输出打印新建目录的绝对路径与处理的文件数；
任何失败都向标准错误输出原因并以退出码 2 结束。

## 快照结构

```text
SNAPSHOT/
├── data/          # 文件原始字节，保留相对目录结构
│   └── ...
└── manifest.json  # UTF-8 JSON 清单
```

清单示例：

```json
{
  "version": 1,
  "files": [
    { "path": "note.txt" },
    { "path": "嵌套 目录/二进制 文件.bin" }
  ]
}
```

- `version` 固定为 `1`。
- `files` 为数组，每项的 `path` 使用 `/` 分隔相对路径。
- 源目录中名为 `manifest.json` 的文件照常备份（保存在 `data/` 下）。
- 空目录不保留；空源目录可备份并恢复为空目录。

## 安全与失败语义

- 备份目标（快照目录）与恢复目标必须事先不存在；已有文件、目录或符号链接一律拒绝覆盖。
- 快照目录不得位于源目录内；恢复目录不得位于快照目录内。
- 备份要求源目录存在且为目录，源目录自身及内部不得含符号链接或非普通文件。
- 恢复前严格校验清单：清单必须存在且为合法 JSON，版本受支持，字段类型正确，
  且不得含绝对路径、上级目录（`..`）分量、重复路径或解析后越出数据目录/恢复目录的路径。
- 清单引用的数据必须存在、为普通文件且不是符号链接；任何一项缺失即整体失败，不跳过。
- 所有可预先判定的错误在创建目标目录之前检出，因此失败时不会新建目标目录或越界文件；
  复制阶段失败会清理本次新建的目标目录。
