# 本地版本备份与恢复工具

面向普通项目文件的本地备份工具。当前实现最小的单快照功能：递归备份普通文件目录，并可将快照恢复到全新目录。

仅依赖 Python 3 标准库（`os` / `pathlib` / `shutil` / `json` / `argparse`）。

## 用法

```bash
# 备份：将 SOURCE 递归备份到新建的 SNAPSHOT 目录
python backup.py backup SOURCE SNAPSHOT [--checksum] [--exclude PATH]...

# 恢复：将 SNAPSHOT 恢复到新建的 DEST 目录
python backup.py restore SNAPSHOT DEST

# 预览：只完成恢复前校验并打印本次计划，不创建 DEST、不复制文件
python backup.py restore SNAPSHOT DEST [--file PATH]... --dry-run
```

成功时退出码为 0，标准输出打印新建目录的绝对路径与处理的文件数；
任何失败都向标准错误输出原因并以退出码 2 结束。

## 快照结构

```text
SNAPSHOT/
├── data/          # 文件原始字节，保留相对目录结构
│   └── ...
└── manifest.json  # UTF-8 JSON 清单
```

清单示例：

```json
{
  "version": 1,
  "files": [
    { "path": "note.txt" },
    { "path": "嵌套 目录/二进制 文件.bin" }
  ]
}
```

使用 `--checksum` 备份时，每个文件条目额外包含 `sha256` 字段：

```json
{
  "version": 1,
  "files": [
    { "path": "note.txt", "sha256": "d9120622…" },
    { "path": "空文件.dat", "sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855" }
  ]
}
```

- `version` 固定为 `1`。
- `files` 为数组，每项的 `path` 使用 `/` 分隔相对路径。
- 源目录中名为 `manifest.json` 的文件照常备份（保存在 `data/` 下）。
- 空目录不保留；空源目录可备份并恢复为空目录。
- `--checksum` 为可选项：`sha256` 是快照中该文件原始字节的 SHA-256 摘要，
  为 64 位小写十六进制字符串；空文件按空字节串计算
  （`e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`）。
  不传该选项时清单不包含摘要字段，格式与旧版完全一致。

## 排除文件（备份）

- `--exclude PATH` 可重复指定，只影响本次备份；不传时备份源目录中的全部
  普通文件，行为与旧版完全一致。
- `PATH` 以源目录为基准、使用 `/` 分隔，与文件相对路径**逐字**匹配：
  保留大小写、中文与空格，不转换分隔符，不展开目录，也不做通配符匹配；
  重复指定同一路径只排除一次。
- 被排除的文件不写入 `data/` 与 `manifest.json`，成功输出的文件数只计算
  实际收录的文件；清单仍为版本 1，路径排序不变，不新增排除规则字段。
  与 `--checksum` 同用时只为收录的文件记录摘要。
- 全部文件被合法排除时仍成功：清单 `files` 为空数组、`data/` 为空目录，
  报告文件数 0。
- 排除参数在创建快照前校验，下列情况一律退出码 2、标准输出为空、
  不创建快照、不改动源目录：
  - 空字符串、绝对路径、带盘符路径、含反斜杠、或含空/`.`/`..` 路径分量：
    标准错误包含“排除路径无效”与原始参数；
  - 形态合法但指向目录、或不与任何普通文件逐字匹配：
    标准错误包含“排除项未匹配普通文件”与原始参数。
- 排除参数不绕过源目录的完整安全检查：源目录内的符号链接与非普通文件
  仍触发现有拒绝行为。

## 摘要校验（恢复）

- 恢复在创建目标目录之前，对清单中**所有**带 `sha256` 的文件进行校验
  （即使通过 `--file` 只选择其中一部分，未选中的条目同样参与校验）。
- 仅字段缺省表示无摘要；同一清单可混合有摘要与无摘要的条目，
  无摘要的旧快照仍可照常恢复。
- `sha256` 存在但为 `null`、非字符串、长度不是 64、或含 `0-9`、`a-f`
  以外字符时，退出码 2 并指出“摘要格式错误”及对应相对路径。
- 文件字节与合法摘要不一致时退出码 2，指出“摘要校验不一致”及路径；
  校验时文件无法读取同样退出码 2。
- 以上任一失败都不创建恢复目标、不打印成功摘要，也不改动源目录与快照。

## 恢复预览（--dry-run）

- `restore` 附加 `--dry-run` 时只执行与实际恢复完全相同的恢复前检查，
  随后在标准输出打印**一行** JSON 对象（末尾换行）并以退出码 0 结束，
  标准错误为空。可与重复的 `--file` 同用；命令仍接收 SNAPSHOT 与 DEST。
- JSON 对象仅含以下字段：
  - `snapshot`：解析后的快照目录绝对路径；
  - `destination`：解析后的目标绝对路径；
  - `files`：本次选择的文件数；
  - `paths`：本次选择的相对路径字符串数组，按 Unicode 码点升序排列，
    不受清单排列与 `--file` 参数顺序影响。
- 不指定 `--file` 时选择清单中的全部文件；指定时继续逐字匹配相对路径，
  保留大小写、中文与空格，重复选择只计一次，不展开目录或通配符。
  预览只展示清单内选中的文件，不纳入 `data/` 中的额外文件。空快照输出
  `files` 为 0、`paths` 为空数组。
- 预览不创建 DEST 及其父目录，不创建临时文件或报告文件，也不复制、
  修改或删除快照内容。
- 预览沿用实际恢复的全部清单、数据、摘要及路径边界校验：未选中的文件
  同样参与检查。数据缺失、非法清单路径、摘要格式错误或校验不一致均以
  退出码 2 结束、标准输出为空，标准错误沿用现有原因与相关路径；选择不
  存在的条目、目标已存在或解析后位于快照目录内也按现有拒绝结果结束，
  不输出部分计划。
- 预览只确认现有的恢复前检查，不探测目标写入权限，也不承诺之后的实际
  复制一定成功。不带 `--dry-run` 的 restore 输出与失败语义保持不变。

## 安全与失败语义

- 备份目标（快照目录）与恢复目标必须事先不存在；已有文件、目录或符号链接一律拒绝覆盖。
- 快照目录不得位于源目录内；恢复目录不得位于快照目录内。
- 备份要求源目录存在且为目录，源目录自身及内部不得含符号链接或非普通文件。
- 恢复前严格校验清单：清单必须存在且为合法 JSON，版本受支持，字段类型正确，
  且不得含绝对路径、上级目录（`..`）分量、重复路径或解析后越出数据目录/恢复目录的路径。
- 非空字符串 path 在任意位置含空字符（U+0000，JSON 中写作 `\u0000`）时，
  restore 与 verify 一律退出码 2、标准输出为空，标准错误指出“清单路径包含空字符”
  并以 JSON 字符串形式展示原始路径（空字符显示为字面转义序列 `\u0000`，
  不输出实际空字符或异常堆栈）；不删去空字符、不截断路径。restore 即使通过
  `--file` 只选择有效文件，未选条目含空字符也整体拒绝且不创建恢复目标。
  文件内容中的零字节是正常数据，不属于损坏路径。
- 清单引用的数据必须存在、为普通文件且不是符号链接；任何一项缺失即整体失败，不跳过。
- 所有可预先判定的错误在创建目标目录之前检出，因此失败时不会新建目标目录或越界文件；
  复制阶段失败会清理本次新建的目标目录。
