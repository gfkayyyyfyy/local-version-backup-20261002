# 本地版本备份与恢复工具

面向普通项目文件的本地备份工具。当前实现最小的单快照功能：递归备份普通文件目录，并可将快照恢复到全新目录。

仅依赖 Python 3 标准库（`os` / `pathlib` / `shutil` / `json` / `argparse`）。

## 用法

```bash
# 备份：将 SOURCE 递归备份到新建的 SNAPSHOT 目录
python backup.py backup SOURCE SNAPSHOT [--checksum] [--exclude PATH]... [--exclude-dir PATH]...

# 备份预览：只完成备份前校验并打印本次收录计划，不创建 SNAPSHOT、不复制文件
python backup.py backup SOURCE SNAPSHOT [--checksum] [--exclude PATH]... [--exclude-dir PATH]... --dry-run

# 恢复：将 SNAPSHOT 恢复到新建的 DEST 目录
python backup.py restore SNAPSHOT DEST [--file PATH]... [--dir PATH]...

# 预览：只完成恢复前校验并打印本次计划，不创建 DEST、不复制文件
python backup.py restore SNAPSHOT DEST [--file PATH]... [--dir PATH]... --dry-run
```

成功时退出码为 0，标准输出打印新建目录的绝对路径与处理的文件数；
任何失败都向标准错误输出原因并以退出码 2 结束。

## 快照结构

```text
SNAPSHOT/
├── data/          # 文件原始字节，保留相对目录结构
│   └── ...
└── manifest.json  # UTF-8 JSON 清单
```

清单示例：

```json
{
  "version": 1,
  "files": [
    { "path": "note.txt" },
    { "path": "嵌套 目录/二进制 文件.bin" }
  ]
}
```

使用 `--checksum` 备份时，每个文件条目额外包含 `sha256` 字段：

```json
{
  "version": 1,
  "files": [
    { "path": "note.txt", "sha256": "d9120622…" },
    { "path": "空文件.dat", "sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855" }
  ]
}
```

- `version` 固定为 `1`。
- `files` 为数组，每项的 `path` 使用 `/` 分隔相对路径。
- 源目录中名为 `manifest.json` 的文件照常备份（保存在 `data/` 下）。
- 空目录不保留；空源目录可备份并恢复为空目录。
- `--checksum` 为可选项：`sha256` 是快照中该文件原始字节的 SHA-256 摘要，
  为 64 位小写十六进制字符串；空文件按空字节串计算
  （`e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`）。
  不传该选项时清单不包含摘要字段，格式与旧版完全一致。

## 排除文件（备份）

- `--exclude PATH` 可重复指定，只影响本次备份；不传时备份源目录中的全部
  普通文件，行为与旧版完全一致。
- `PATH` 以源目录为基准、使用 `/` 分隔，与文件相对路径**逐字**匹配：
  保留大小写、中文与空格，不转换分隔符，不展开目录，也不做通配符匹配；
  重复指定同一路径只排除一次。
- 被排除的文件不写入 `data/` 与 `manifest.json`，成功输出的文件数只计算
  实际收录的文件；清单仍为版本 1，路径排序不变，不新增排除规则字段。
  与 `--checksum` 同用时只为收录的文件记录摘要。
- 全部文件被合法排除时仍成功：清单 `files` 为空数组、`data/` 为空目录，
  报告文件数 0。
- 排除参数在创建快照前校验，下列情况一律退出码 2、标准输出为空、
  不创建快照、不改动源目录：
  - 空字符串、绝对路径、带盘符路径、含反斜杠、或含空/`.`/`..` 路径分量：
    标准错误包含“排除路径无效”与原始参数；
  - 形态合法但指向目录、或不与任何普通文件逐字匹配：
    标准错误包含“排除项未匹配普通文件”与原始参数。
- 排除参数不绕过源目录的完整安全检查：源目录内的符号链接与非普通文件
  仍触发现有拒绝行为。

## 排除目录（备份）

- `--exclude-dir PATH` 可重复指定，只影响本次备份；不传时不排除任何目录，
  行为与旧版完全一致。可与 `--exclude`、`--checksum` 任意组合使用。
- `PATH` 以源目录为基准、使用 `/` 分隔，与目录相对路径**逐字**匹配：
  保留大小写、中文与空格，不转换分隔符，也不做通配符匹配。匹配的目录
  及其全部后代文件不写入快照；按路径分量比对，因此排除 `cache` 不影响
  `cache-old` 或 `cache.txt`。
- 重复指定同一目录或父子目录重叠指定时取并集；源目录中存在的空目录
  同样是合法匹配。
- `--exclude` 的单文件排除仍按完整源目录判断是否匹配：即使该文件同时
  位于被排除目录内，只要它是源目录中的普通文件即算匹配，不报错。
- 被排除的文件不写入 `data/` 与 `manifest.json`，成功输出的文件数只计算
  实际收录的文件；清单仍为版本 1，路径排序与摘要规则不变，不新增排除
  规则字段。全部文件被排除时仍成功：清单 `files` 为空数组、`data/` 为
  空目录，报告文件数 0。
- 排除目录参数在创建快照前校验，下列情况一律退出码 2、标准输出为空、
  不创建快照、不改动源目录：
  - 空字符串、绝对路径、带盘符路径、含反斜杠、或含空/`.`/`..` 路径分量：
    标准错误包含“排除目录路径无效”与原始参数；
  - 形态合法但不存在、或指向普通文件而非目录：
    标准错误包含“排除目录未匹配普通目录”与原始参数。
- 排除目录参数不绕过源目录的完整安全检查：被排除目录自身或其内部含
  符号链接、非普通文件时，仍触发现有拒绝行为。

## 备份预览（backup --dry-run）

- `backup` 附加 `--dry-run` 时只执行与实际备份完全相同的备份前检查
  （源目录、排除项与快照目标），随后在标准输出打印**一行** JSON 对象
  （末尾换行）并以退出码 0 结束，标准错误为空。可与 `--checksum`、
  重复的 `--exclude` / `--exclude-dir` 任意组合；命令仍接收 SOURCE 与
  SNAPSHOT。
- JSON 对象仅含以下字段：
  - `source`：解析后的源目录绝对路径；
  - `snapshot`：解析后的快照目标绝对路径；
  - `files`：本次收录的普通文件数；
  - `paths`：本次收录的相对路径字符串数组（`/` 分隔），按 Unicode
    码点升序排列。
- 预览沿用实际备份的源目录、快照目标与排除项检查：源目录不存在、不是
  目录、自身或内部含符号链接或非普通文件、目录遍历失败，目标已有文件、
  目录或符号链接，或目标解析后位于源目录内，均以退出码 2 结束、标准
  输出为空，标准错误沿用现有原因；非法 `--exclude` 值报告“排除路径
  无效”，合法但未匹配普通文件报告“排除项未匹配普通文件”，
  `--exclude-dir` 分别报告“排除目录路径无效”或“排除目录未匹配普通
  目录”，均附原始参数。重复排除与父子目录排除仍取并集；位于排除目录
  内的单文件排除仍按完整源目录匹配。排除区域仍参与安全检查。
- 预览（无论成功或失败）不创建 SNAPSHOT 及其父目录，不复制文件，不生成
  清单、临时文件或报告，不改动源目录或已有目标。空源目录或合法排除全部
  文件时，预览仍成功并返回 `files` 为 0、`paths` 为空数组。
- `--checksum` 在预览中不计算摘要、不读取文件内容；预览不探测目标写入
  权限，也不保证随后的实际复制成功。源文件未变时，去掉 `--dry-run` 后
  在同一目标备份，清单路径与预览一致，文件字节与源文件一致。不带
  `--dry-run` 的 backup 输出、版本 1 清单及 restore、verify 的行为保持
  不变。

## 目录选择恢复（restore --dir）

- `--dir PATH` 可重复指定，只影响本次恢复；与 `--file` 一样作用于现有
  版本 1 快照，选择清单中位于该目录下的**全部后代文件**，恢复时保留
  它们相对于快照的完整路径（`docs/sub/b.bin` 恢复到
  `DEST/docs/sub/b.bin`）。
- `PATH` 使用 `/` 分隔，按路径分量与清单路径**逐字**匹配：保留大小写、
  中文与空格，不转换分隔符、不展开通配符。选择 `docs` 收录
  `docs/a.txt` 与 `docs/sub/b.bin`，但不收录 `docs-old/a.txt` 或
  `docs.txt`；与目录同形的清单文件也不算后代。
- `--dir` 与 `--file` 可以合用，所有选择取并集；重复目录、父子目录
  重叠（如 `docs` 与 `docs/sub`）以及重复文件只恢复一次。只有
  `--file` 与 `--dir` 两类选择都未提供时才恢复清单中的全部文件。
- 目录选择**仅依据清单路径**：不依赖源目录是否存在，也不把 `data/` 中
  未列入清单的文件纳入结果。形态合法但没有任何清单文件作为后代的目录
  （包括未记录的空目录）一律退出码 2、标准输出为空，标准错误包含
  “选择的目录未包含快照清单文件”与原始参数，不创建恢复目标。
- 下列目录参数形态统一按退出码 2 拒绝，标准输出为空，标准错误包含
  “目录选择路径无效”与原始参数：空字符串、以 `/` 开头、带 Windows
  盘符（如 `C:/a`）、含反斜杠、或含空、`.`、`..` 路径分量。
- 任一目录（或合用的任一 `--file`）不匹配就整体失败：不创建恢复目标，
  不返回部分结果；不存在的单文件仍按原有的“选择的路径未在快照清单中”
  拒绝。
- 与 `--dry-run` 同用时仍输出一行 JSON 预览，字段不变：`files` 与
  `paths` 反映并集去重后的选择，`paths` 按 Unicode 码点升序排列；
  预览不创建目标及其父目录。
- 与不带 `--dir` 时相同，预览和实际恢复都先校验整个快照：未选中文件
  的数据缺失或摘要不一致仍导致退出码 2、标准输出为空且不创建目标。

## 摘要校验（恢复）

- 恢复在创建目标目录之前，对清单中**所有**带 `sha256` 的文件进行校验
  （即使通过 `--file` / `--dir` 只选择其中一部分，未选中的条目同样参与
  校验）。
- 仅字段缺省表示无摘要；同一清单可混合有摘要与无摘要的条目，
  无摘要的旧快照仍可照常恢复。
- `sha256` 存在但为 `null`、非字符串、长度不是 64、或含 `0-9`、`a-f`
  以外字符时，退出码 2 并指出“摘要格式错误”及对应相对路径。
- 文件字节与合法摘要不一致时退出码 2，指出“摘要校验不一致”及路径；
  校验时文件无法读取同样退出码 2。
- 以上任一失败都不创建恢复目标、不打印成功摘要，也不改动源目录与快照。

## 恢复预览（--dry-run）

- `restore` 附加 `--dry-run` 时只执行与实际恢复完全相同的恢复前检查，
  随后在标准输出打印**一行** JSON 对象（末尾换行）并以退出码 0 结束，
  标准错误为空。可与重复的 `--file` / `--dir` 同用；命令仍接收
  SNAPSHOT 与 DEST。
- JSON 对象仅含以下字段：
  - `snapshot`：解析后的快照目录绝对路径；
  - `destination`：解析后的目标绝对路径；
  - `files`：本次选择的文件数；
  - `paths`：本次选择的相对路径字符串数组，按 Unicode 码点升序排列，
    不受清单排列与 `--file` 参数顺序影响。
- 不指定 `--file` 与 `--dir` 时选择清单中的全部文件；指定时 `--file`
  继续逐字匹配相对路径，`--dir` 按路径分量匹配目录下的全部后代文件，
  保留大小写、中文与空格，重复选择只计一次，不展开通配符。两类选择
  取并集、去重；`paths` 按 Unicode 码点升序排列，不受清单排列与参数
  顺序影响。预览只展示清单内选中的文件，不纳入 `data/` 中的额外文件。
  空快照输出 `files` 为 0、`paths` 为空数组；任何合法目录都无清单
  后代时仍按退出码 2 失败。
- 预览不创建 DEST 及其父目录，不创建临时文件或报告文件，也不复制、
  修改或删除快照内容。
- 预览沿用实际恢复的全部清单、数据、摘要及路径边界校验：未选中的文件
  同样参与检查。数据缺失、非法清单路径、摘要格式错误或校验不一致均以
  退出码 2 结束、标准输出为空，标准错误沿用现有原因与相关路径；选择不
  存在的条目、目标已存在或解析后位于快照目录内也按现有拒绝结果结束，
  不输出部分计划。
- 预览只确认现有的恢复前检查，不探测目标写入权限，也不承诺之后的实际
  复制一定成功。不带 `--dry-run` 的 restore 输出与失败语义保持不变。

## 安全与失败语义

- 备份目标（快照目录）与恢复目标必须事先不存在；已有文件、目录或符号链接一律拒绝覆盖。
- 快照目录不得位于源目录内；恢复目录不得位于快照目录内。
- 备份要求源目录存在且为目录，源目录自身及内部不得含符号链接或非普通文件。
- 恢复前严格校验清单：清单必须存在且为合法 JSON，版本受支持，字段类型正确，
  且不得含绝对路径、上级目录（`..`）分量、重复路径或解析后越出数据目录/恢复目录的路径。
- 非空字符串 path 在任意位置含空字符（U+0000，JSON 中写作 `\u0000`）时，
  restore 与 verify 一律退出码 2、标准输出为空，标准错误指出“清单路径包含空字符”
  并以 JSON 字符串形式展示原始路径（空字符显示为字面转义序列 `\u0000`，
  不输出实际空字符或异常堆栈）；不删去空字符、不截断路径。restore 即使通过
  `--file` / `--dir` 只选择有效文件，未选条目含空字符也整体拒绝且不创建
  恢复目标。
  文件内容中的零字节是正常数据，不属于损坏路径。
- 清单引用的数据必须存在、为普通文件且不是符号链接；任何一项缺失即整体失败，不跳过。
- 所有可预先判定的错误在创建目标目录之前检出，因此失败时不会新建目标目录或越界文件；
  复制阶段失败会清理本次新建的目标目录。
