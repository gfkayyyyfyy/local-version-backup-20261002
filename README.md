# 本地版本备份与恢复工具

建设面向普通项目文件的本地备份产品，逐步覆盖备份计划、文件快照、变更清单、完整性校验、版本浏览、指定文件恢复、保留策略预览和操作报告。

计划采用：Python 3 标准库 / pathlib / shutil / hashlib / json / argparse。

当前仓库实现最小可用功能（Python 3 标准库，无第三方依赖）：

- `python backup.py backup SOURCE SNAPSHOT`：递归备份源目录中的普通文件。
- `python backup.py restore SNAPSHOT DEST`：依据清单恢复到新的目标目录。

快照目录内：`data/` 按源目录相对结构保存文件原始字节，`manifest.json` 为
UTF-8 JSON 清单（`version: 1`，`files` 数组每项含斜杠分隔的相对 `path`）。
源文件即使名为 `manifest.json` 也正常备份；空源目录可备份并恢复为空目录。

安全约束：目标路径必须事先不存在（含悬空符号链接），绝不覆盖已有内容；快照
目录不得位于源目录内，恢复目录不得位于快照目录内；拒绝符号链接与非普通文件；
恢复时严格校验清单（JSON、版本、字段类型、绝对路径、`..`/`.` 分量、重复路径、
路径越界）及数据文件（缺失、符号链接、非普通文件）。所有可预先判定的错误在
创建目标目录之前失败；失败信息输出到标准错误，退出码 2，成功退出码 0。成功时
标准输出第一行为新建目录的绝对路径，第二行为处理文件数（如 `4 files`）。
